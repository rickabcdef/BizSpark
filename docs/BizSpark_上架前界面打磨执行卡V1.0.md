## 第 0 页 · 全员必读（9 人签字）

### 一句话

**功能不动、逻辑不动，只把"看起来像不像一家成熟软件公司做出来的产品"这一件事做到位。** 结果是大卖，不是重构。

### 版本口径（老板 2026-11-18 拍板）

- **第一版对外只出纯英文售卖包**（`en-US`），面向欧美、重点美国本土；本阶段不做其他语言版本，不做多语言切换。
- `zh-CN` 中文包仅作老板本人本地自检 / 熟练操作用，**不上架、不外发、不进任何商店素材**；中文文案只做与英文的语义对齐，不作为对外打磨对象。
- 第一版先跑通、先试水；功能细节的精细化留到第二版，本轮不扩功能、不加复杂度。

### 三条死规矩（违反即返工）

1. **不改业务逻辑。** 引擎打分、诊断、保存、导出 PDF、价格槽桥接、离线降级、激活校验等任何计算与流程代码，一律不动。本卡所有改动只落在：样式表、语言包文案、模板里的图标 / 版式 / 内联样式。
2. **不新增功能、不删保留文件。** 不新增加按钮、加页面、加筛选 / 排序 / 对比 / 账号 / 云同步；`Activate.vue`、`activate.*` 语言包键、`apps\core\license\` 全部原样保留，一个文件一行都不删。
3. **文案只走语言包。** 界面字符串只能出现在 `locales\en-US.json`、`locales\zh-CN.json`；组件模板里不得新写死英文 / 中文。中英两包键必须一一对应，**差集为 0**。

### 合规红线（文案与界面绝对不能碰）

| 类别 | 禁止出现 | 说明 |
|---|---|---|
| 暴富承诺 | `get rich`、`millionaire`、`wealth secret`、`secret`、`guarantee`、`quick money` | 美国商店审核与口碑风险 |
| 后台 / 算法词 | `algorithm`、`AI score`、`recommended by`、`based on intelligent`、`engine`、`weight`、`score`、`浪潮`、`算法`、`权重`、`引擎`、`商机库` | 结果页底部统计小字（查完多少条 / 排除多少条 / 留下几条）是唯一例外 |
| 匹配度 | 结果页、详情页不得出现百分比、`% MATCH`、匹配度字样 | 序号只留 `01 / 03` |
| 隐私口径 | 不得暗示账号、云同步、联网上传、后台遥测 | 唯一外联是每月一次点子库更新检查，不带用户数据 |
| 拼写 | 对外英文包一律美式拼写 | 见第 5 节拼写清单 |

### 打磨方向（老板已定调，不许跑偏）

- **气质**：大气、克制、可信，硅谷成熟工具感；不要花哨堆砌、不要炫光、不要 emoji 混搭。
- **配色**：中性冷白底 + 深墨蓝侧边 + 沉稳橙主按钮 + 宽松留白；去掉暖黄底和金色点缀。
- **图标**：全站统一一套线性图标，描边粗细一致、跟随当前色；不再混用 emoji、几何符号、字符图标。
- **文案**：英文直白、口语、日常高频词，像美国同事在跟你说话；不绕弯、不端着、不叫卖。

## 第 4 节 · 文案打磨清单（语言包负责人）

### 4.1 原则

- 英文用美国日常口语：短句、主动语态、第二人称 `you`；避免名词堆砌、被动腔、营销形容词。
- 一条文案只说一件事；按钮词用动词开头（Find / See / Save / Open / Back）。
- 中英两包语义对齐，但不是逐字直译；中文自检版以老板能快速看懂流程为准。
- 所有改动只改语言包值，不改键名、不改模板插值占位符 `{amt} {lo} {hi} {ver} {ideas} {dir} {kb} {pages} {rank} {total}`。

### 4.2 重点改写键（英文优先，中文对齐）

| 键 | 现状问题 | 打磨方向 |
|---|---|---|
