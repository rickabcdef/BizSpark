## 2. 产品结论（R-01…R-09）

| 号 | 规则 | 为什么 |
|---|---|---|
| **R-01** | **3 条就是本次收成。** 不给「换一批 / 加载更多 / 下一页」；不给无限翻页 | 用户买的不是选择权，是「替我定了」。多一个刷新按钮，就多一次把地垄指给他看 |
| **R-02** | **「再找一次」的唯一正解 = 改一个条件重新诊断。** 三个入口统一回问卷 P02：`← Change my answers`(03)、`Find new ideas`(06)、`Find another idea`(05) | 变的是**输入**，不是往库里挪游标。集合根本不会被空转耗尽，因为不存在「同一排来回走」 |
| **R-03** | **到边界不弹提示、不静默回卷。** 不写「您已看完」，也不把游标悄悄绕回第一条；收束为「这 3 条里最贴你的是第 1 条」 | 诚实收口不丢人，静默回卷才丢人；而最体面的收口是让用户感觉不到边界 |
| **R-04** | **不记「看过什么」。** 不建曝光表、不存 `seen_ids`、不做去重历史。`state.json.saved` 仍只存用户**主动保存**的「我的点子」 | 一旦开始记，就得管损坏、迁移、换机；更糟的是它等于承认「有个库在被消耗」，迟早漏到界面上 |
| **R-05** | **匹配度百分比不进前台。** 分数仅后台排序用；结果卡 / 详情页 / 我的点子 / PDF 全部不渲染；保留编号 `01 / 03` 与一句 Why | 规则引擎给不出「95% 置信度」，那个数字还在暗示「下一个可能更高分」，是贪婪的燃料 |
| **R-06** | **不扩容、不生成、不联网。** 26 行当 / 312 条第一版够用；不为「防点空」加内容生产 | 真有人反复点，多半是前三条没打动他（诊断质量），不是库小。别另起炉灶 |
| **R-07** | **「同条件同答案」是工程确定性，不是对用户的承诺。** 系统里不出现「缓存答案 + 有效期」这个概念；每次现场重算，库没变、条件没变，自然一样 | 用户感知不到，也不该感知到 |
| **R-08** | **「变」只由月度 delta 内容版本驱动；不做 TTL、不做 3 天/7 天/半月保鲜期。** 换血后同条件重算，新商机自然浮上来、老商机沉下去；**不保证至少换一条** | 换过血之后的「没变」是有分量的没变，说明原来那三条确实更适合他 |
| **R-09** | **界面零时间痕迹**：不显示「更新于 X 月」、不显示库版本、不显示倒计时、不显示「已为你保留」。`last_result` 仅超时兜底，**不设有效期、不因日期换结果、不显示「上次结果」** | 任何把时间摆到用户面前的控件，都是在把地垄指给他看 |

> 一句话：**情绪价值来自「稳」和「准」，不来自「装作还有」。** 确定性本身就是情绪价值——「它一直那样、不找你麻烦」。为了显得强而让答案随日期抖两下，是一次性开心，不是生意。

## 3. 算法结论（R-10…R-14，含缺陷单搬入）

| 号 | 规则 | 落点 |
|---|---|---|
| **R-10** | **成本唯一真源**：`cost_rows[]` 由按国家/版本的基准表查表得出，条目只存 `cost_refs[]`；禁止「先有 total 再按 4:3:3 拆三行」；`min_capital` = 合计 = 结果页标签 = PDF 成本表，**四处同源** | D / V-13 |
| **R-11** | **同 `template_id` 在 Top3 最多 1 条**。打分**前**按 `template_id` 分组、每组取 top1 再全局排；不引入相似度重排 | C / K-14 |
| **R-12** | **地段建模成 `segment_override`，字段白名单焊死**：只允许改获客渠道、客单价、竞争度、合规提示；`cost_refs[]` 明确列为**不可覆盖** | D / C |
| **R-13** | **用户条件真跑**：资金档作为数值区间参与硬过滤，结果页 lead 与 `QuizAnswers` 同源；`CountryOverride` 严格按 `countries[]` 取，缺值**报错、不静默回退默认英语区** | C / D / F |
| **R-14** | **构建期校验**，运行期只留一条极轻兜底（Top3 撞车就降级换一条）：同 template 成本一致、`min_capital == sum(items)`、二手不贵于全新、渠道国家交集非空、前台零百分比 / 零时间字段、零曝光字段 | A / V-13 / V-14 / V-15 |

> 继承自《缺陷单》的 DEF-01…DEF-05 全部有效；本单只**改写 R7→R-05**，其余 R1–R6、R8 原样纳入（对应关系：R1→R-11、R2→R-10、R3→R-10、R4→R-12、R5→R-13、R6→R-13、R8→修复卡 FIX-B1）。
> **不为了防点空放开 `template_id` 去重**（退回「一个生意三个地址」），**不偷偷改用户条件制造「不一样」**（用户一定会发现，信任归零比重复更贵）。
