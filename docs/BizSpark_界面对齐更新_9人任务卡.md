打开 `en/html/01-welcome.html` 搜这几个词：

### 三条死规矩（违反即返工）

1. **不改版。** 配色、栅格、字号、圆角、留白、深色欢迎页、橘色主 CTA、9 屏顺序、页面跳转关系——一个像素都不动。本阶段没有"顺手优化一下"这回事。
2. **不新增功能。** 对齐期间冒出来的任何想法，进差异台账、贴 `V2 Backlog`、当场关掉，不排期、不摆控件、不写进第一版。
3. **方向别反：以实现改向基线，不是以基线改向实现。** 真工具里做歪了 → 改实现；做多了 → 从界面拿掉；做少了 → 按基线补上。**任何"要不把图改成我们实现的样子"的提议，PM 直接驳回。**

## 6. 常见误判 10 条（贴墙上，省得反复解释）

1. **「图挺好看的，顺手把按钮挪正一点」** → 不行，本阶段 0 次视觉变更。
2. **「功能都做了，摆出来呗」** → 不摆。做多了收进抽屉，界面只留第一版有的。
3. **「只读状态做成下拉，用户改起来方便」** → 不行，`state-pill` 不可点。
4. **「打开文件夹先放个按钮占位置」** → 不行，A-05 真能用才出现。
5. **「问卷选完自动跳下一题更顺」** → 不行，基线是 Back / Next 两个按钮，**照 HTML 做**。
6. **「中文版加个语言切换多好」** → 不行，软件内无语言切换按钮，中文包是内部自检包。
7. **「`From $120` 也是金额，删了吧」** → 别删，那是商机内容数据，不是商品售价。
8. **「检查更新放设置里不算新功能吧」** → 算。第一版不摆。
9. **「实现跟图差一点，把图改成实现的样子省事」** → 方向反了，**改实现**。
10. **「我这份 HTML 看着像旧的，但应该差不多」** → 停手，做 10 秒自查，找 PM 重领。
