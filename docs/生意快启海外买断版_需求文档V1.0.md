## 0. 这份文档怎么读

**一句话产品定义：**

> 用户买下一个桌面图标。双击 → 答 5 道题 → 看到 3 个他能做得成的生意 → 导出一张能打印的纸。全程不登录、不联网也能用、不追问、不学会。

**贯穿全文档的铁律（来自已确认的商业判断，开发不得自行突破）：**

1. **用户端只留"小"**：答几题 → 出 3 条 → 存一张纸。界面上不允许出现"商机库""权重""版本""引擎""浪潮"等后台词汇。
2. **复杂全部沉到看不见的那一面**：商机库、打分、差量更新、授权，做厚做全，但一秒钟都不占用户注意力。
3. **核心逻辑在客户端本地**：不放在云端。服务器只做"可选的文件更新"，挂了、忘续费了、断网了，用户无感，功能完整。
4. **不给自己挖坑**：不接支付接口、不做账号体系、不做订阅、不依赖任何按年续费的运行时服务。
5. **好看是第一位**：界面是产品的全部第一印象。高保真稿即验收基线，开发实现以英文版 `en/html/` 为准。
6. **英文为主、中文为镜**：产品只有一个版本，就是英文版。中文版只是把英文版界面上的字换成中文，给自己看、自己用、自己练熟；不单独改设计、不单独加功能、不上架（详见 §11）。
7. **价格不写死**：商品售价是发布参数，不是产品属性。全项目不出现任何金额；售价由商店后台设置，工程侧只留一个可配置的价格源（详见 §12）。

> 文档写得厚，是给开发和你自己看的"阴面"；用户看到的那一面必须始终薄。这两件事不矛盾。

## 1. 商业约束（先写死，避免返工）

| 编号 | 约束 | 说明 |
|---|---|---|
| C01 | 只做海外 | 不在国内销售、不接国内支付、不做中文售卖页、不办国内经营性互联网资质 |
| C02 | 买断制 | 一次付费（金额由商店后台设置），永久可用；无到期、无续费提醒、无自动扣款 |
| C03 | 支付归平台 | 软件内**零支付代码**。Store 由商店收款；分销平台由平台收款并抽成 |
| C04 | 无账号 | 不注册、不登录、不绑定邮箱、不云同步、不找回密码 |
| C05 | 联网可用但非必需 | 联网仅用于商机库月度差量更新与首次激活校验；核心诊断与导出完全离线 |
| C06 | 零后端依赖 | 静态托管几个 JSON/CSV 文件即可，无 FastAPI 常驻服务、无数据库、无大模型 API 账单 |
| C07 | 桌面工具 | 交付物必须是 `.msix/.exe`（Windows）与签名 `.app/.dmg`（Mac），不是网页快捷方式 |
| C08 | 渠道差异化授权 | Store 版不做授权码；分销版做轻量激活码（详见 F10） |
| C09 | 第一版不做手机端 | Windows + macOS 双端打透后再考虑 iOS/Android |

**明确不做的清单（本期红线）：** 登录注册 / 云同步 / 用户账号 / 支付接口 / 订单与退款后台 / 订阅与会员到期 / 社区与评论 / 用户上传点子 / 联网调大模型 / 全量 200 国本地化 / 移动端 / 消息推送 / 每日签到 / 积分体系。

## 2. 用户与场景

### 2.1 目标用户（首版 3 类）

| Persona | 处境 | 他凭什么掏钱 |
|---|---|---|
| 副业尝试者（US/UK 上班族） | 有 $500–2k 积蓄，每周 <10h，搜过 "side hustle ideas" 但全是空话 | 想要 3 条"钱够、时间够、明天能动手"的具体生意 |
| 本地小生意人（SG/PH 店主、修理工） | 有手艺、有设备，想再加一条收入线 | 想要按自己国家写的获客渠道和成本表 |
| 第一次创业的人（AU/CA 自由职业者） | 怕压库存、怕亏、怕复杂 | 想要一张纸，别给他一个"系统" |

### 2.2 核心使用闭环（验收以这条链路为准）

```
双击图标 → 首屏 1 个按钮 → 5 道题（每屏 1 题）→ 3 张结果卡
→ 点开 1 张 → 一页详情（成本 / 7 步 / 定价 / 获客 / 坑 / 合规）
→ 导出 PDF 到本地 → 关掉
```
**目标耗时：首次打开到拿到 PDF ≤ 3 分钟。** 用户中途不需要做任何"设置""选择模式""理解概念"。

### 2.3 复购逻辑（买断制下的"回来"）

不靠会员到期，靠：第一个生意做成了 → 想找第二个点子 → 桌面上那个图标还在 → 双击，还是那 5 道题、还是 3 张卡、什么都不用重新学。**"它一直那样，没找过我麻烦"就是买断工具的"不用管了"。**

## 3. 设计原则（UI 验收标准）

| 原则 | 落地要求 |
|---|---|
| 一屏一动作 | 每页只有一个主按钮、一个主要决策；不并列两个同等强的 CTA |
| 不弹错 | 网络失败、更新失败、无匹配结果，一律静默降级，禁止弹红色报错弹窗 |
| 不解释后台 | 不展示"匹配度算法""商机库版本""趋势标签"给普通用户（结果页仅一句 Why this fits you） |
| 隐私即卖点 | 侧栏常驻 "One-time purchase · No subscription"，顶栏常驻 "All yours, on this device" |
| 视觉基线 | 暖白 `#F7F5F0` + 深墨蓝 `#0E2438` + 橘 `#F2653A` 仅用于主 CTA；Inter 字体；22px 圆角；大留白；克制阴影；无渐变滥用、无插画堆砌 |
| 一致性 | 左侧固定 246px 深墨蓝导航 + 顶部 70px 细 bar；9 页同一壳体，欢迎页为唯一深色整屏变体 |

## 4. 功能需求（逐条写细）

> 优先级：**P0 = 首版必须有**；P1 = 首版尽量有；P2 = 明确放后续版本。

### F01 启动与首屏（P0）

- **入口**：双击桌面图标 / Store 启动。
- **首次启动**：0.8s 内出首屏，不做向导、不请求权限、不弹"是否允许联网"、不放启动广告。
- **首屏内容**（对应 `01-welcome.html`）：
  - 主标题 `You don't need a business plan. You need one idea.`
  - 副文案一句讲清：5 道题 → 3 个生意 → 一张可打印的纸
  - **主 CTA 仅一个**：`Find my 3 ideas →`
  - 次链接：`Open my saved ideas`（弱化为文字按钮）
  - 底部信任行：`One-time purchase · Yours forever` / `Works offline` / `Your answers never leave this device`（**不含金额**，由价格配置渲染）
- **非首次启动**：主 CTA 不变；若存在本地存档，`My ideas` 侧栏项显示条数角标。
- **异常**：本地存档损坏 → 静默重建空存档，不弹窗、不丢其他数据。
- **验收**：冷启动到可点击 ≤ 1.5s；首屏无可滚动内容（1440×900 一屏装下）。

### F02 诊断问卷（P0）

- **结构**：5 题，**每屏 1 题**，顶部 5 点进度条（已完成 / 当前 / 待办）。
- **题目定义（写死，不许加题）**：

| # | 题目 | 控件 | 选项 | 默认 |
|---|---|---|---|---|
| Q1 | Where are you starting? | 单选（国家卡） | US / CA / UK / AU / SG / PH | 系统区域猜测，猜不中默认 US |
| Q2 | How much can you put in to start? | 单选 | <$500 / $500–2k / $2k–10k / $10k+ | 无默认，必须选 |
| Q3 | Hours per week? | 单选 | <10h / 10–25h / Full-time | 无默认 |
| Q4 | What do you already have? | **多选** | 车 / 厨房 / 电脑 / 设计 / 写代码 / 闲置房间 / 本地人脉 / 什么都没有 | 可一个都不选 |
| Q5 | How much risk is OK? | 单选 | 亏了不能影响生活 / 可接受小亏 / 能扛一次全亏 | 无默认 |

- **交互细节**：
  - 每个选项是一张大卡（图标 + 标题 + 一行解释），点击即选中并高亮橘边；选中后 **自动 0.35s 进下一题**，不需要再点"下一题"（这也是"用户只动一下"）。
  - 保留 `← Back`，返回不丢已选答案。
  - Q4 多选时提供 `Done` 按钮（唯一例外）。
  - 无键盘输入、无自由文本、无必填校验弹窗；未选时主按钮置灰。
- **数据**：答案只写内存，落盘仅作为"上次答案"缓存（用户可在设置里清）。
- **验收**：全程点击次数 ≤ 6 次（Q4 多算 1 次）；任何一题断网都不受影响。

### F03 本地匹配引擎（P0，核心逻辑，客户端内）

> 这是"护城河的一半"，**必须打包在客户端**，不得做成 API。

- **输入**：F02 的 5 组答案 + 本地商机库。
- **① 硬过滤**（不满足直接剔除，不参与打分）：
  `capital_tier` 必须覆盖所选资金档；`hours_per_week` 不得高于所选档；`countries[]` 含所选国家；`legal_blocks[]` 不含该国；`status = active`。
- **② 软打分**（权重写死在客户端配置里，不给用户调）：

| 维度 | 权重 |
|---|---|
| 资金贴合度 | 20% |
| 技能 / 已有资源匹配 | 20% |
| 时间匹配 | 15% |
| 风险承受匹配 | 15% |
| 回本速度 | 10% |
| 本地渠道可得性 | 10% |
| **趋势新鲜度** | **5%** |
| 复购型偏好 | 5% |

> **趋势新鲜度只给 5%**：用户要的是"他做得成的生意"，不是"最酷的技术"。禁止为了追 AI 浪潮把 Uber 司机硬塞 5 条 Agent 创业。

- **③ 输出克制**：
  - 只取 **Top 3**（不是 10 条、不是"查看更多"分页）
  - 每条生成一句 `Why this fits you`，用答案里的 concrete 词（"$500–2,000""under 10 hours""a laptop"），不许写"基于智能算法为您推荐"
  - `maturity = saturated` 的条目**不进 Top 3**，但保留在库里、不删除
  - 与本地存档中已看过的 `id` 相同则降权 15%，避免每次都推同样三条
- **④ 降级**：若硬过滤后不足 3 条 → 放宽时间档一次 → 仍不足则展示实际条数（1–2 条）+ 一句 `Try a slightly bigger budget next time`。**禁止显示"无结果"空白页或报错。**
- **验收**：312 条库、最低配笔记本上，从答完第 5 题到出结果 ≤ 300ms；全程无网络请求。

### F04 结果页（P0）

- 三张并排卡片（对应 `03-results.html`），每张固定 7 个元素：
  `01/03 编号` · `94% MATCH`（右上角小字）· 标题 · 一句话说明 · `Why this fits you` 引句 · 3 个标签（起步成本 / 时间 / 线上或本地）· 主按钮 `See the one-page plan →`
- 顶部一句："Based on $500–$2,000, under 10 hours a week, a laptop, and United States."（把用户答案复述一遍，让他确认没跑偏）
- 底部弱化操作：`Change my answers` / `Save all three`；再加一行小字统计（"312 ideas checked locally / 289 filtered out / 3 worth your Monday"）——**这行是给"值回票价"用的，不是展示算法**。
- **禁止**：筛选器、排序下拉、对比勾选、分页、广告位、"升级解锁更多"。

### F05 点子详情页（P0，产品价值全在这页）

左侧主内容区 6 个模块，右侧 sticky 一页纸预览卡（对应 `04-detail.html`）：

| 模块 | 必须包含的字段 | 写法要求 |
|---|---|---|
| M1 这生意卖什么 | `one_liner` + 2 句展开 | 说清谁付钱、为什么现在有人买 |
| M2 起步成本拆解 | `cost_breakdown[]` 逐项列，末行合计 | **逐项列钱，禁止"大概几千"**；合计用橘色 |
| M3 前 7 步 | `steps[1..7]` | 每步一个动词开头（Pick / Write / Print / Walk in / Offer / Deliver / Ask），可勾选 |
| M4 定价与回本 | `pricing_hint` + `payback_days` | 给一个具体数字（如 $49/month，20 家回本） |
| M5 第一批客户从哪来 | `first_customers[]`，**按国家不同** | 美国 Thumbtack/Etsy/Nextdoor；SG/PH Facebook/WhatsApp/Google Maps；不许写"社交媒体推广"这种废话 |
| M6 三个坑 + 一句合规 | `pitfalls[3]` + `compliance_note` | 坑写具体动作；合规只一句提醒（sales tax / business name / 上门揽客许可），不写成法律意见 |

- 右侧预览卡：一张微微倾斜的 A4 缩略图 + `Export my plan ↓` 主按钮 + `Back to 3 ideas` 次按钮 + `🔒 Nothing is uploaded. Ever.`
- **验收**：详情页内容 100% 来自本地库字段，渲染不依赖网络；滚动时右侧预览保持可见。

### F06 启动包生成与导出（P0）

- **触发**：点 `Export my plan`。
- **产物 A（必须）**：单页 PDF，文件名 `BizSpark-Plan-{slug}.pdf`，含 M1–M6 全部内容，A4 / Letter 双版式自适应，页脚 `BizSpark · one-time purchase · generated on this device`，**无水印、无二维码、无"分享给朋友"**。
- **产物 B（P1）**：成本表 CSV（可选勾选），同目录。
- **保存**：弹出系统原生"另存为"，默认路径 `Documents/BizSpark/`；记住路径（F11）。
- **生成位置**：**100% 本地渲染**，不上传、不经过任何服务器、不生成在线链接。
- **完成页**（对应 `05-export.html`）：大绿勾 + 文件名/大小/路径 + `Open folder` / `Find another idea` + 一行"no link, not something that can expire"。
- **异常**：磁盘满 / 无写权限 → 提示换一个文件夹（唯一允许的提示），不丢已填步骤。
- **验收**：导出 ≤ 2s；断网导出成功；PDF 单页、可直接打印。

### F07 我的点子（P0，本地留存）

- 结果页 / 详情页可 `Save`；`My ideas` 页列出本地条目（图标 / 标题 / 保存日期 / 起步成本 / 匹配度 / `Open`）。
- 支持：`Compare two ideas`（并排两栏，仅显示成本、时间、回本三项）、`Clear saved list`（二次确认）。
- 存储：单个本地文件（JSON/SQLite 皆可），**无账号、无同步、无云端副本**；重装系统后丢失属预期行为，需在隐私说明里写明。
- 空态：不是空白，一句 `Double-click Find my 3 ideas. It takes 40 seconds.`
- 底部提示：`Made your first sale? Come back and run the 5 questions again with a bigger budget.`（轻引导复访，不做推送）

### F08 商机库（P0，护城河本体）

**8.1 规模与分布（baseline v1.0，随安装包冻结）**

- 总量 **312 条**（在你定的 150–300 档上略放量，便于按 26 行业均分），覆盖 **26 个行业**、6 国、4 个资金档。
- 建议分布（避免全是 AI）：本地服务 28% / 线上副业 24% / B2B 小外包 18% / 内容与数字产品 14% / 手作与线下小生意 10% / AI 与智能体相关 6%。
- **低门槛能上手的生意永远占大头**；AI 类是"跟上时代"，不是把库写成 AI 专区。

**8.2 每条商机的结构化字段（开发照此建数据文件）**

| 组 | 字段 | 用途 |
|---|---|---|
| 身份 | `id`, `title`, `one_liner` | `id` 全局唯一，更新靠它覆盖 |
| 硬条件 | `min_capital`, `capital_tier`, `hours_per_week`, `countries[]`, `online_or_offline`, `legal_blocks[]` | F03 ① 硬过滤 |
| 软标签 | `skills_needed[]`, `assets_needed[]`, `risk_level`, `payback_days`, `recurring`, `channel_ids[]` | F03 ② 打分 |
| 内容 | `cost_breakdown[]`, `steps[7]`, `pricing_hint`, `first_customers[]`, `pitfalls[3]`, `compliance_note` | F05 详情页直接渲染 |
| 时代 | `wave`, `trend_tags[]`, `first_seen`, `maturity` | 支撑月度换挡 |
| 元信息 | `version`, `updated_at`, `status` | 差量合并 |

- `wave` 枚举（可累加，不按年份硬编码）：`mobile-internet → ai-llm → ai-agent → bi-agent → …`（留空位）
- `maturity`：`emerging / growing / mature / saturated`
- **老商机不删**：只把 `maturity` 调成 `saturated` 并降权，永不出 Top 3。

**8.3 按国家适配字段**：币种（USD/CAD/GBP/AUD/SGD/PHP）、`first_customers[]` 本地渠道、`compliance_note` 一句话、`legal_blocks[]`。同一 `id` 可带多国变体，不复制整条。

**8.4 数据格式**：`baseline_v1.json`（UTF-8，压缩包内置），纯文本、可读、可手工编辑——**你每月唯一要干的活儿就是编辑它**。

**8.5 内容纪律**：不写"做自媒体""开网店"这类空话；每条必须能回答"第一步明天早上干什么"。

### F09 月度增量更新（P1，联网的唯一理由）

> 对应你举的例子：**1 号是发布窗口，不是商机自动长出来**。3 月 1 号库里出现 AI 商机，前提是你在 2 月把它们写进 3 月包；7 月 1 号出现商业智能体商机，同理。**换挡不是替换，是加权迁移**：新条目往上浮，老条目慢慢沉，永不消失。

- **节奏**：每月 **1 号**发布一个 delta 包；客户端启动时静默检查 `manifest.json` 版本号。
- **托管**：Cloudflare Pages / S3 上只放 `manifest.json` + 若干 `delta_YYYY-MM.json`。**无后端框架、无数据库、无常驻进程，成本趋近于零。**
- **四种操作**：`check`（读版本） / `add`（新商机） / `revise`（改字段，如 growing→saturated） / `retire`（标 status，不再参与打分，**不从磁盘删除**）。
- **静默降级（硬要求）**：无网 / 超时 / 404 / 托管到期 / 你忘续费 → **一律静默跳过**，不弹错、不阻塞启动、不降级任何功能。用户用手上那份库照常完整使用。
- **用户可见面**（对应 `08-update.html`）：Library 页只显示"当前版本 + 一条时间线 + ✓ Up to date"，以及右下角一条轻 toast。**普通用户永远不需要点"检查更新"**。
- **免费**：买断用户不因更新再付一分钱，说话算话。
- **日历校准**：你用 2024→2025 打比方说明"时代换挡"，逻辑成立；按真实日历现在已是 **2026 年 11 月**，AI / 智能体商机是**当下存量而非未来**。因此 `baseline_v1.json` 必须**自带**一批 `ai-llm / ai-agent / bi-agent` 条目（故为 312 条里那 6%），再从 **2026-12-01** 起按月换血。否则用户一打开就觉得工具落后两年。
- **回滚**：delta 合并前先备份上一版库文件，合并失败自动回退，用户无感。

### F10 授权激活（P0，分渠道，绝不做成登录）

| 渠道 | 做法 |
|---|---|
| Microsoft Store（付费下载） | **不写任何授权代码**，商店已验证购买，打开即完整版 |
| Mac App Store | 同上，StoreKit 由系统处理 |
| Gumroad / Lemon Squeezy 等分销 | **轻量激活码**：平台收款后发码，用户在 `07-activate.html` 输入 |

**激活码规格（分销版）：**
- 一码 **最多 3 台设备**（默认 2 台更省事，UI 按 3 台展示）
- 设备识别用**机器指纹**（硬件 ID + 系统信息哈希），**禁止用 IP**（海外用户 IP/VPN 常变，会误伤）
- 首次激活联网校验一次 → 本地写入签名凭证 → **此后完全离线可用，不再回连**
- 提供 `Changed computer? Release a seat` 手动解绑入口（首版邮件处理即可，不做后台）
- 激活 ≠ 登录：无用户名、无密码、无账号、无"欢迎回来"
- 页面必须原样展示：`One-time purchase` / `No subscription` / `No auto-renewal` / `No account, no email` / `Core features work offline`
- **验收**：拔网线后重启软件，功能 100% 可用；换第 4 台设备时给的是"释放一台"的温和提示，不是"授权失败"。

### F11 设置（P1，六个旋钮封顶）

对应 `09-settings.html`，**只允许这 6 项**：国家 / 语言 / 导出路径 / 月度库检查开关 / 跟随系统深浅色 / 匿名崩溃日志（默认关）。
- 隐私说明一句话写死：`Your answers, your saved ideas and your exported plans never leave this device.`
- About 区显示：版本、库版本、Licence（One-time · activated）、Account（None）。
- **禁止**新增：账号、通知、主题商店、高级设置、实验功能、数据上传开关。

### F12 客户端自动更新（P1）

- Store 版：完全交给商店更新，客户端不写 updater。
- 分销版：`electron-updater` 类静默检查新安装包，提示"新版本可用，下次启动时更新"，**不强制、不阻断当前使用**。
- 与 F09 分离：**库更新 ≠ 程序更新**，两者互不依赖。

### F13 空态、异常与边界（P0，统一口径）

| 场景 | 行为 |
|---|---|
| 首次启动 / 无网 | 一切正常，用 baseline 库 |
| 更新失败 / 托管挂了 | 静默跳过，界面无任何变化 |
| 匹配结果不足 3 条 | 放宽一次时间档，展示 1–2 条 + 温和一句，绝不空白页 |
| 本地存档损坏 | 静默重建，不弹窗 |
| 导出路径不可写 | 只提示换文件夹 |
| 第 4 台设备激活 | 引导释放席位，不报"授权失败" |
| 系统深浅色切换 | 跟随，不闪白 |
| 用户断网一个月 | 完全无感，回来后一次性合并缺失的 delta |

**全局禁令**：任何红色错误弹窗、任何"请检查网络后重试"、任何需要用户理解的报错码。

### F14 非功能需求（P0）

- **性能**：冷启动 ≤1.5s；诊断 ≤300ms；导出 PDF ≤2s；内存占用 ≤300MB。
- **包体**：Windows ≤120MB，Mac ≤120MB（若用 Tauri 可压到 40MB 以内）。
- **离线**：核心链路 100% 离线，飞行模式可完整跑通"答题→3 条→PDF"。
- **隐私**：零用户数据出设备；唯一出网请求是月度 `manifest.json`（不含任何用户标识）。
- **可访问性**：键盘可操作、对比度 ≥4.5:1、系统字号跟随。
- **崩溃日志**：默认关闭；开启后仅含错误码与版本，不含答案、不含点子、不含文件路径。

## 5. 技术方案（对齐已确认的边界）

```
┌──────── 用户设备（核心逻辑全在这） ────────┐
│ 界面      Vue3                             │
│ 桌面壳    Tauri（推荐，包小）/ Electron      │
│ 诊断引擎  Python 编写 → 打包进客户端本地运行 │
│ 商机库    baseline_v1.json（安装包内置）     │
│ 导出      PDF / CSV 本地渲染                │
│ 存档      本地单文件                        │
└──────────────┬───────────────────────────┘
               │ 可选、月度、静默
┌──────────────▼───────────────────────────┐
│ 静态托管：manifest.json + delta_*.json     │
│ 无 FastAPI 常驻 / 无数据库 / 无大模型账单   │
│ 挂了用户无感，忘续费用户无感               │
└──────────────────────────────────────────┘
```

- **不用 UniApp**：它不产出 Windows / macOS 桌面安装包。
- **Python 的正确位置**：写诊断引擎与库工具，打包进客户端；**不**放在服务器上让用户联网调用。
- **FastAPI 本期不使用**（若以后做云端增值，再作为独立可选服务，且绝不能成为买断功能的前提）。
- **不接 Stripe / PayPal / 内购 SDK**：钱由平台收。
- **打包产物**：Windows `MSIX`（Store）+ `.exe`（分销）；Mac 签名 `.app/.dmg`（Store 与分销各一份）。
- **第二版才考虑**的用户自带 API Key 深化（用户填自己的 Key、费用自担），本期一行不做。

| 风险 | 应对 |

## 11. 双版本：英文为主，中文为镜

### 11.1 为什么这么定

**产品只有一个版本，就是英文版。** 它直接面对海外用户，上架 Microsoft Store / Mac App Store / 分销平台，商品页、截图、评论、收据全是英文。

中文版存在的唯一理由：**自己先看得明白、用得熟练，才讲得清楚、才卖得动。** 连自己都没跑通那 5 道题、没导出过那张纸，就没法判断海外用户会在哪一步犹豫。所以中文版是给自己用的自检副本，不是第二条产品线，也不是"国内版"。

> 这一条与 C01「只做海外、不做中文售卖页」不冲突：中文版**不对外分发、不上架、不出现在任何商品页素材里**，只在自己电脑上跑。

### 11.2 中文版怎么做的（施工口径）

| 项 | 处理 |
|---|---|
| 页面 / 文件 | 9 个，文件名与英文版完全一致，一一对应 |
| 结构 | HTML 标签、class、id、层级、栅格 **100% 不动** |
| 样式 | `assets/style.css` 是英文版那一份的**原样拷贝**，一个字节都不改 |
| 视觉 | 配色、留白、圆角、阴影、字号、深色欢迎页、橘色主 CTA、那个微微倾斜的纸片预览——全部不变 |
| 字体 | 拉丁字符仍走 Inter，中文由系统 CJK 字体回退；**不换中式字体、不加中国红/金/纹样/印章** |
| 交互 | 选中即进下一题、卡片跳转、开关、toast，全部一致 |
| 内容 | **只替换界面上可见的文字**（含导航、面包屑、按钮、标签、提示、时间线、隐私说明） |
| 不译 | `BizSpark`、`Microsoft Store`、`Mac App Store`、`PDF`、`CSV`、`Google Maps / Yelp / Etsy / Shopify / Nextdoor`、激活码样例 `BZSP-K7Q2-M9XA`、文件名、版本号、`AI` |

> 换句话说：**中文版要长得像"英文版换了行字"，不能长得像"一个中国软件"。** 因为你要练的，正是海外用户将来看到的那个东西。

### 11.3 同步纪律（防两版跑偏）

1. 任何改动——文案、字段、按钮、页面、配色——**先改英文版**。
2. 再把同一处改动**逐字镜像**到中文版，只换字，不换结构。
3. 两版同时重新出 9 张截图与总览图，逐页比对。
4. **中文版禁止**：单独加功能、单独调布局、单独改按钮位置、单独加"切换语言"入口、单独做第三语言、单独先进化到 v1.1。
5. 出现分歧时，**以英文版为准**，中文版回头对齐，不反过来。

### 11.4 中文版明确不做的事

- ❌ 不做语种切换按钮（软件里一个按钮都不许多）
- ❌ 不做中文商品页 / 中文落地页 / 国内售卖入口
- ❌ 不做中文截图进商店素材
- ❌ 不因中文改字体风格、不加中式装饰
- ❌ 不把中文版单独打包对外发
- ❌ 不因为"中文看起来字少"就顺手挪版式

## 12. 价格配置契约（价格写活，不写死）

> 商品价格随行就市，**是发布参数，不是产品属性**。当前那个定价只是想法，**不得写进任何文件、UI 图、HTML 页面、需求文档或商品文案**。第一版只讲功能，不出现金额。

### 一、第一版：分成销售，客户端不出现价格

Microsoft Store / Mac App Store 付费下载的**售价在 Partner Center / App Store Connect 后台设置**，改价即时生效、不需要重新发版。客户端、静态页、需求文档、UI 截图、商品页文案**只讲功能与购买模式**（`One-time purchase` / `No subscription` / `No auto-renewal`），**一律不出现金额**。

> 这正好是「价格可设置」最省事的形态：**价格本来就不在软件里，在商店后台。**

### 二、唯一价格源

| 层 | 文件 | 说明 |
|---|---|---|
| 静态 HTML 交付 | `assets/pricing.js` | `window.BIZSPARK_PRICING`，改一处、中英两版 18 页全生效 |
| 工程客户端 | `config/pricing.json` + `locales` 的 `price.*` 键 | 构建期注入，运行时只读 |
| 商店售价 | Partner Center / App Store Connect 后台 | 分成销售的实际价格，**不进客户端** |

```json
{
  "display_mode": "hidden",
  "amount": null,
  "currency": "USD",
  "model": "one-time",
  "billing_note": null
}
```

| 字段 | 取值 | 首版 |
|---|---|---|
| `display_mode` | `hidden` / `visible` | `hidden` |
| `amount` | 数字，仅 `visible` 时填写 | `null` |
| `currency` | ISO 4217 | `USD` |
| `model` | `one-time` / `monthly` / `yearly` / `seat` | `one-time` |
| `billing_note` | 可选，如 `per month` | `null` |

**首版配置里没有任何金额；渲染器里也没有写死任何数字——`visible` 时的金额完全由 `amount` 动态生成。**

### 三、三条硬规矩

1. **零硬编码**：全项目（md / docx / HTML / CSS / JS / 截图 / 商品文案）不得出现任何商品售价数字；价格只能由配置渲染。CI 加金额门禁（T-59）。
2. **首版 hidden**：价格占位渲染为纯功能 / 模式文案（如 `One-time purchase · Yours forever`），不渲染数字、不渲染空价格框、**不新增任何用户可见控件**。
3. **后期显示只改配置**：做授权码、包月、包年、订阅制时，把 `display_mode` 改为 `visible`、填 `amount` 与 `model`，一处改动，客户端 / 静态页 / 商品文案同时生效；**仍不加「改价」界面**，界面永远做小。

### 四、边界说明（别误删内容）

商机库里的**起步成本、定价建议、回本金额**（如 `From $120`、`$49/month`）是**内容数据**，不是本商品售价，不受本契约约束，必须保留。门禁只扫描商品售价，不扫描商机内容。
