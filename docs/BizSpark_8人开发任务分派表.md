## 第 0 页 · 全员必读（8 人签字）

### 产品一句话
用户买下一个桌面图标 → 答 5 道题 → 看到 3 个他能做得成的生意 → 导出一张能打印的纸。**不登录、不联网也能用、不订阅。**

### 11 条铁律（违反即返工）
1. 用户端只留「小」：答几题 → 出 3 条 → 存一张纸。
2. 界面不许出现「商机库/权重/引擎/版本/浪潮/算法」等后台词。
3. 核心逻辑 100% 在客户端本地，**不放在云端**。
4. 联网只用于：每月 1 号静默查更新、分销版首次激活。
5. 托管挂了 / 忘续费 / 断网 / 404 → **静默跳过**，不弹错、不阻塞。
6. 软件内零支付代码、无账号、无登录、无订阅、无自动续费。
7. 不依赖任何按年续费的服务、不调大模型 API、无 API 账单。
8. Store 版不写授权码；分销版一码 3 台设备，激活 ≠ 登录，激活后永久离线。
9. 好看是第一位，`en/html/` 高保真稿即像素级验收基线。
10. **英文为主、中文为镜**：改动先改英文版 → 逐字镜像中文版 → 两版同时重出截图。
11. **价格不写死**：商品售价是发布参数，不是产品属性。全项目零金额硬编码；售价由商店后台设置，工程侧唯一价格源 `config/pricing.json`，首版 `display_mode=hidden`、`amount=null`。

### 本期明确不做
登录注册 / 云同步 / 账号 / 支付接口 / 订单退款后台 / 订阅 / 连续包月包年 / 消息推送 / 社区 / 用户上传点子 / 联网大模型 / 自带 API Key / 200 国本地化 / 手机端 / 积分签到 / 分享裂变 / 广告位 / **语言切换按钮** / 中文售卖页 / 国内支付。

### 四条协作规矩
- 跨模块问题先查 V2.0 §7 契约表；查不到由 **A 裁决**并补进契约。
- **H 不写业务代码，但有一票否决权**；用例不过，负责人不进下一周。
- 界面文案只在 `apps/web/src/locales/`；业务层不许写界面字符串；前端不许自己算业务逻辑。
- **任何页面 / 文档 / 截图 / 商品文案都不许写金额**；价格只从 `assets/pricing.js` 读，看到硬编码金额直接打回。

## 第 0 页补充 · 价格配置（人人都要知道）

**第一版只讲功能，不出现价格。** 商店付费下载，售价在 Microsoft Partner Center / App Store Connect 后台设置，改价不用发版，客户端根本不需要知道价格。

| 层 | 文件 | 谁管 |
|---|---|---|
| 静态 HTML | `assets/pricing.js`（改一处、18 页全生效） | B |
| 工程客户端 | `config/pricing.json` + `locales` 的 `price.*` 键 | A / B |
| 商店售价 | Partner Center / App Store Connect 后台 | H |

```json
{ "display_mode": "hidden", "amount": null, "currency": "USD", "model": "one-time", "billing_note": null }
```

首版 `hidden` + `amount=null` → 价格槽渲染纯功能文案（`One-time purchase · Yours forever`），**不显示数字、不显示空框、不加任何按钮**。后期做授权码 / 包月 / 包年 / 订阅时，改 `display_mode=visible`、填 `amount` 与 `model`，一处改动全端生效——**价格写活，但界面还是那么小**。

> 商机库里的 `From $120`、`$49/month` 是**内容数据**，不是商品售价，保留，别误删。
