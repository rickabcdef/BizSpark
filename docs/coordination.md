## 协同纪律（全员）

- 不覆盖别人的代码，不修改别人的功能；可在已有功能上优化或添加自己的功能

- 禁止"我的功能能用了，别人的功能不好用了"——提交前跑通已有验收用例
- 契约改动必须 `contract/` 前缀 PR 并 @全员（§12.1）
